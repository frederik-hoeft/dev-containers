# Dev Containers

## Templates

| Template | Description |
|----------|-------------|
| [java-nextjs](java-nextjs/) | Project-independent Java (Maven) + Next.js development environment |
| [prolog](prolog/) | Prolog development environment |
| [python](python/) | Python development environment |
| [scala](scala/) | Scala development environment |
